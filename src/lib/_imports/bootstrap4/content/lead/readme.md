To skin [Bootstrap v4 Lead](https://getbootstrap.com/docs/4.6/content/typography/#lead).

> **⚠️ Important**
>
> Before [TACC/Core-Styles#683](https://github.com/TACC/Core-Styles/pull/683), this style was applied to `<h2>` elements, because of hsitorical usage of the `<h2>` element as a "lead". Now, this style can and should be applied to `<p>` elements (which is the correct semantic usage of the `lead` class).
