A large, prominent paragraph — e.g. summarizing a page, right under its [`<h1>`](https://developer.mozilla.org/en-US/docs/Web/HTML/Element/Heading_Elements).

> **☝ See Also**
>
> Sites loading Bootstrap should instead see `core-styles.bootstrap4.css`'s (or `bootstrap5.css`'s) restyling of Bootstrap's own [`.lead`](https://getbootstrap.com/docs/5.3/content/typography/#lead) class.

> **⚠️ Warning**
>
> Do not use a heading element (e.g. `<h2>`) for this — use `<p class="s-lead">` instead.
